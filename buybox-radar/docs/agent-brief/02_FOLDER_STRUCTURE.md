## 4. `server/` (package `@radar/server`)

`package.json`: name `@radar/server`, deps/devDeps/scripts per 01 §13 and §15.
`tsconfig.json`: extends base; `types: ["node"]`; `include: ["src","scripts","tsup.config.ts","vitest.config.ts"]`; `noEmit: true`.
`vitest.config.ts`: `environment: 'node'`, `include: ['src/**/*.test.ts']`.
`.env.example`: exactly 01 §14.

### 4.1 Entry & app

| File | Responsibility |
|---|---|
| `src/index.ts` | Load env → create `PrismaClient`, services → `createApp(deps)` → `listen(PORT)`. Register `SIGTERM`/`SIGINT` for graceful shutdown (close server, `prisma.$disconnect()`). |
| `src/app.ts` | `export interface AppDeps { searchService: SearchService; companyService: CompanyService }` and `export function createApp(deps: AppDeps): express.Express`. Order: `helmet` → `cors` → `express.json({limit:'100kb'})` → `pino-http` → routes under `/api` (health, meta, searches with rate limiter, companies) → `/api` 404 via `notFound` → static web + SPA fallback (only if `WEB_DIST_DIR` set & exists) → `errorHandler`. **No DB access in this file.** |
| `src/config/env.ts` | zod-parse `process.env` per 01 §14; export typed `env`. Throw with a readable message on invalid config. |

### 4.2 `lib/`

| File | Responsibility / exports |
|---|---|
| `lib/errors.ts` | `class AppError extends Error { constructor(public status: number, public code: string, message: string, public details?: unknown) }`; helpers `notFound(msg)`, `validationError(details)`. |
| `lib/logger.ts` | `export const logger = pino({ level: env.LOG_LEVEL })`. |
| `lib/prisma.ts` | Singleton `export const prisma = new PrismaClient()`. |
| `lib/cache.ts` | `createSearchCache(opts:{max:number; ttlMs:number}): { get(k): SearchResponse|undefined; set(k, v): void; clear(): void }` wrapping `lru-cache`. |
| `lib/hash.ts` | `canonicalizeBuyBox(b: BuyBox): BuyBox` (sorted/lowercased per 01 §7.1) and `buyBoxHash(b: BuyBox): string` (sha256 hex via `node:crypto`). |
| `lib/csv.ts` | `toCsv(headers: string[], rows: (string|number|null|undefined)[][]): string` — BOM, CRLF, RFC-4180 quoting, injection guard (01 §8.1). |
| `lib/csv.test.ts` | Tests per 01 §16. |

### 4.3 `middleware/`

| File | Responsibility |
|---|---|
| `validate.ts` | `validateBody(schema)` and `validateQuery(schema)` factories: parse with zod; on failure `throw new AppError(400,'VALIDATION_ERROR','Invalid request', err.flatten())`; on success assign parsed data to `req.body` / `res.locals.query`. |
| `notFound.ts` | Responds `404` with `NOT_FOUND` error shape for unmatched `/api/*`. |
| `errorHandler.ts` | 4-arg handler: `AppError` → its status/code/message/details; `ZodError` → 400; anything else → log with pino, respond `500 INTERNAL_ERROR` "Something went wrong". |

## 7. Import & layering rules (enforce in review)

```
web/*        → may import: @radar/shared, react libs        ✗ never import server/*
server/routes → services, middleware, @radar/shared         ✗ no prisma, no domain logic

shared/*     → zod only
```

## 8. Naming conventions

- API JSON uses `camelCase`. Enums for status are upper snake (`SHORTLISTED`).
- React components `PascalCase.tsx` with named exports (no default exports except `App`).
- Hooks `useXxx`. Constants `UPPER_SNAKE`. Types/interfaces `PascalCase`. Booleans `isXxx`/`hasXxx`.
- Tests sit beside the code: `foo.ts` ↔ `foo.test.ts` (except `__tests__/api.test.ts`).
